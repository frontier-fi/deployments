# Deployment framework

Task runner for deploying contracts and recording their addresses. Each deployment is a task: build info, inputs, a deploy script, artifacts, and per-network outputs.

No tasks are registered yet. Active tasks go in `tasks/`, one-off scripts in `scripts/`, and replaced tasks in `deprecated/`. How to add and run one is in [DEPLOYING.md](DEPLOYING.md).
